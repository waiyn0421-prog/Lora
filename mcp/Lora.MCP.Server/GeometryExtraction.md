# Selected Revit geometry extraction

`lora_get_element_geometry` requires 1–25 unique numeric element IDs. It does not run a whole-model geometry scan and does not accept category-wide geometry extraction requests. Revit element resolution is performed against the active document protected by the sidecar identity provider and loopback client checks.

The sidecar requests Revit `Element.get_Geometry(Options)` with non-visible geometry excluded and Fine detail. It reports solid counts, volumes and surface areas; face areas; edge curves; mesh triangle counts and at most three sample triangles per mesh; explicit curves with lengths/endpoints; geometry instances; Location; and element bounding boxes. Nested family geometry is enumerated with `GeometryInstance.GetSymbolGeometry()` in symbol-local coordinates and records each `GeometryInstance.Transform` in order. Curve and mesh sample points are transformed through the recorded chain to the owning host document's internal coordinate frame. Solids and faces retain their local geometry descriptors and carry the same transform provenance; consumers must apply that chain for coordinate-specific use.

Entity output is paged independently (`entity_offset`, `entity_limit`) and capped at 200 total entities per request; geometry traversal is capped at depth 8 and 5,000 geometry objects per request. Each element reports separate Geometry, Location, and Bounding Box statuses, warnings, and entity counts. A missing element is a failure record. API errors and caps mark extraction incomplete. The tool does not inspect linked documents, infer host transforms for links, perform clash tests, or make physical-clearance claims. `clearance_status` remains `unverified`.

The Revit API method semantics are described in Autodesk's [GeometryInstance API reference](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/fe25b14f-5866-ca0f-a660-c157484c3a56.htm), including the distinction between symbol-local geometry and instance geometry. The current implementation intentionally reads symbol geometry and carries transforms as provenance. Mocked tests do not prove nested transform order or API assembly compatibility in any Revit host; that requires targeted live read-only tests on Revit 2023–2026.
