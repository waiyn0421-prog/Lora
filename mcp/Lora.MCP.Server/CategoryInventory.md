# Read-only Revit category inventory

`lora_get_category_inventory` reports host-document element counts using the actual `Category.Id` mapped to `BuiltInCategory` enum values. Discipline assignment uses exact enum member names for the explicit Architecture, Structural and MEP lists in the Revit-side provider. Display names are informational only. Categories without a built-in enum mapping remain `unknown`; built-in categories outside those lists remain `other`.

The explicit map includes architectural stair runs, landings, supports, stringers, risers/trisers and stair rail components; structural connection parts and tendons; and MEP duct/pipe/flex/fabrication insulation and lining categories plus wire insulation. The installed Revit 2024 API assembly contains all 89 mapped enum names. That metadata check is not a runtime compatibility claim for Revit 2024, and no Revit 2023/2025/2026 assemblies were available for this check. No cable-tray or conduit insulation category was added by name inference; the inspected Revit 2024 enum did not expose a matching dedicated category.

The tool scans non-type element instances and element types separately, reporting their totals and element-type counts by category. It provides three independent bounded pages: matching instance details (`offset`/`limit`), failure records (`failure_offset`/`failure_limit`), and category summaries (`category_offset`/`category_limit`). Type counts are not folded into instance totals; structural discipline for wall/floor types remains unknown because the discriminator is an instance property. Walls are split using `Wall.StructuralUsage` and floors using `Floor.IsStructural`; inaccessible or unknown property values stay in the unknown discipline and make completeness false. Counts describe successfully read category records. If category access fails or scanning reaches its cap, matching totals and `has_more` can be unknown; `inventory_complete` remains false. Per-instance type, family, level, Location and bounding-box reads are performed only for the returned page of supported Architecture, Structural and MEP model instances.

The detail route reports `model_instance`, `annotation`, `view_specific`, `link_instance`, `no_category` or `other`. This is a category/element-kind index, not a physical-obstruction decision. Category membership and the Location/bounding-box evidence do not establish physical clearance. Solid, mesh, face and edge extraction are not performed. Links are counted as link instances; linked document geometry is not traversed or transformed into host coordinates. Clearance stays `unverified` and coordinate-transform behavior is untouched.

The sidecar route is read-only, requires the existing identity provider to confirm the active document, and is called only through the pinned loopback endpoint with before/after identity checks. Mocked tests cover the category logic and route contract. Runtime compatibility and actual `BuiltInCategory` enumeration behavior still require a controlled Revit-host test for each claimed version; no Revit 2023–2026 runtime validation is inferred from unit tests.
