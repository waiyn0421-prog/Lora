# Lora command capability registry

This registry is descriptive metadata extracted from the current `Lora.tab/**/bundle.yaml`, command scripts, and shared helpers. It is used only for capability explanations and recommendations. The MCP engine never imports or executes ribbon scripts.

All commands are source-inspected, not runtime-validated here across Revit versions. The repository targets Revit 2023–2026; that target statement is not a claim that every command was tested in every version.

| Exact ribbon title | Purpose and required input | Supported context and verified limitations | Model/external effect |
|---|---|---|---|
| **Family Generator** | Build a category-specific family from a Revit family template or a copy of a source RFA; choose fields, shared parameter file, output path/name; separately confirm project binding/loading. | Project document plus compatible family/template and supported category. Does not compose tag label graphics; existing/template labels must be checked. | Creates an RFA and may create shared definitions, bind parameters, and load family into project. |
| **Tag Studio** | Create a tag design with parameter setup preview and confirmation, or inspect an external RFA. | Editable project for setup; external family for inspect flow. Setup has a project transaction. JSON design output is not an authored tag family. | Setup creates/reuses definitions and project bindings; inspect only reads the RFA; optional JSON file output. |
| **Auto Dim** | Choose dimension profile/rules, style, offsets/spacing, and confirm preview. | Active Floor Plan, Ceiling Plan, or Engineering Plan. Supports straight walls and compatible hosted door/window references; curved walls or missing references can be skipped. Columns, beams, grids, floors, stairs are scan-only. | Creates Revit dimensions after confirmation in a transaction. |
| **Data Sync** | Select a schedule and export destination, or choose an XLSX exported by Lora with matching IDs/baselines. | Project document with an eligible element schedule and workbook access. Import only applies values changed from baseline; blank cells are no-ops; read-only, calculated/formula, unsupported, unmatched, and ElementId fields are skipped. Preserve hidden workbook IDs/headings. | Export reads Revit and writes XLSX. Import writes supported parameter values in a transaction. |
| **Draw Area Boundary** | Select Detail/Model Lines; choose/create an Area Plan and scheme; set endpoint tolerance. | Floor/Engineering/Area Plan with a resolvable level. Converts supported bound horizontal lines and arcs; sloped/nonplanar/unsupported curves may be skipped. Does not place Area elements. Custom scheme create/delete routes to native Revit workflow; non-protected rename exists. | May create an Area Plan, creates Area Boundary Lines, and may rename a scheme. |
| **TableGen** | Choose CSV, target Legend/Drafting View, title/layout settings and available text style. | Revit project with CSV and a usable `TextNoteType`. Imports CSV cells as-is using Revit text notes/detail curves. | Creates/duplicates a view and adds text/grid elements in a transaction; activates the view. |
| **InPlace to Family** | Select/pick an in-place family; provide name, RFT template, category, material/subcategory and solid options; choose whether to delete the original. | Revit project with a valid in-place model and compatible family template. Geometry/material conversion can warn or fail on unsupported solids/settings. | Writes an RFA, loads and places a new instance; optional original deletion is exposed in its UI. |
| **Family Version Audit** | Select RFA files/folder for a metadata batch scan, or select one RFA and a target Revit version for compatibility review. | Header scan uses `BasicFileInfo`. Content review hashes the file before/after, temporarily opens a family in the running Revit host, inventories supported fields, and closes with `Close(False)`. Only a newer saved major format is automatically classified incompatible; all other content remains manual review because the target-version API is not simulated. | No transaction, save, load, conversion, reconstruction or project write. The compatibility scan is bounded and does not certify geometry or behavior not listed in its report. |
| **Tag Creation** | Choose Parameter Generator or Tag Generator readiness flow. Parameter Generator additionally needs MEP categories, shared parameter definitions/file and binding choices. | Editable project and script-supported MEP categories. Tag Generator checks readiness but does not automatically author/load a tag-family RFA and does not place tags. | Parameter Generator creates/binds shared parameters. Readiness flow reads project data. |
| **Refresh** | Select elements or pick pipes, ducts, cable trays, conduits; required Lora parameters must be writable/bound. | Revit project with supported MEP elements and usable floor/geometry. Missing floors/geometry are skipped or marked for manual review. Source declares Revit 2023–2026 targets; not runtime-tested here. | Writes relative elevation, size/service/type/status parameters in a transaction. |
| **Hide Section** | Open a plan view that is placed on a sheet and confirm. | Active non-template plan view with sheet association; hides matching marker symbols in the active view. It does not delete section views. | Changes hidden state of view marker elements in a transaction. |
| **View Range** | Activate a 3D view for preview, select/pick a plan view, set Top/Cut/Bottom/View Depth plane settings, apply. | The target is a plan view, not the active 3D preview. Template control or invalid plane combinations may restrict edits. | Edits the plan view range in a transaction; preview graphics are temporary. |
